# 100× Pitchlens

The previous app failed on real video because it never measured the match. The working loop is:

`video → detect → track → team → optional homography → possession + candidates → human review`

Implemented in this branch:

- Local YOLO + ByteTrack/IoU engine
- Two-pass kit clustering before possession
- Homography only when landmarks exist
- Event cooldowns; goals always need review
- `POST /api/v1/analyze-local`
- CLI writer for tracking JSON
- Review-room overlay, radar, JSON import

Still required for elite tracking: football-specific weights, labelled eval set, calibration wizard, Re-ID, job queue.
